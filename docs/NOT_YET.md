# EH3D-PROJECT-PASSPORT: not yet

Good ideas that are not in the current version. Writing them here keeps anybody from implementing them early or twice.

| Idea | Why not yet | Revisit when |
|---|---|---|
| Standards-compliance reporting | It needs the verifier and the applicable standards first | the verifier has its first version |
| A signature on the passport | A signature needs a key policy that nobody has decided, and no key is ever stored in a repository | the owner decides how the keys are kept |
| Rebuilding the manufacturing files from a passport | It needs the tools that make the files to be callable from a program | the manufacturing tools can be run from a passport |
| A passport as an archive that holds its files | The passport points at the files with their hash, which keeps it small and the files in place | a project has to travel as one file |
| A task kind for the server | The server has no kind of task for a passport yet | the server accepts tasks from the engines |
